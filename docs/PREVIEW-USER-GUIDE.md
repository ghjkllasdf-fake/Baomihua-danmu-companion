# 爆米花弹幕伴侣：使用指南

这是供你直接观看视频、收集使用反馈的试用版，尚未完成正式版的全部验收。请保留原来的旧版文件夹；这个包不包含旧版程序、旧 API 地址或个人配置。

本版保留自动匹配、同剧绑定弹幕源及统一向左入场，并修正跳转时旧弹幕反向闪现、切换窗口后弹幕消失的问题。先正常观看即可；后续开发优先根据你实际遇到的问题调整。

preview.13 修复了后台启动后从托盘打开工作台白屏的问题，并使用“电视、爆米花与弹幕点线”的新应用和托盘图标。旧版请先从托盘退出，再启动新版。

## 开始使用

1. 将 ZIP **完整解压**到自己有写权限的文件夹，例如下载目录。不要在压缩软件里直接打开 BAT，也不要覆盖正在使用的旧版文件夹。
2. 双击 `检查文件.bat`，确认文件与发行清单一致。它只检查文件，不下载或安装软件。清单用于发现文件缺失或损坏，不是数字签名。
3. 双击 `启动弹幕助手新版.bat`。程序先驻留任务栏右侧的托盘区，点击图标才打开工作台；图标可能在“显示隐藏的图标”内。包内已有 PowerShell 7.6.6；普通使用不需要安装 Node、npm 或 .NET SDK。
4. 电脑需要已有 Microsoft Edge WebView2 Runtime。缺少或无法找到时，错误窗口会给出微软官方下载地址；按提示获取 Evergreen 独立安装程序（x64），安装后重新打开助手。程序不会静默安装。不要为此关闭安全设置或把弹幕助手改为管理员运行。
   如需暂时使用旧版，请回到保留的旧版文件夹，双击 `启动弹幕助手.bat`。当前候选包不含旧版入口，需要使用原来的文件夹。
5. 用普通权限打开网易爆米花和视频。工作台顶部会显示识别到的作品、集数、进度及同步状态。

## 连接弹幕服务

- 在左侧展开“弹幕服务连接”，填入自己的 `danmu_api` 完整 API 地址。工作台显式关闭了浏览器表单自动填充和密码保存。地址只保留于本次会话，关闭后需要重新填写；不要把含 Token 的地址贴到截图、日志或公开反馈中。
- 填好有效地址后会自动开始：读取当前片名，搜索匹配来源，选择对应分集并加载弹幕，无需点击搜索、选集或加载。成功后工作台显示“已自动匹配”及所用来源。
- 同一作品换集、切换作品或播放器信息恢复后，会自动跟进；切换时取消旧任务，旧视频的下载结果不会加载到新视频。电影只有一个条目时可自动选择；多集作品读不到集数时不会猜第一集。
- 首次找到多个匹配来源时，会逐一读取**当前集**的实际可用弹幕数，比较完成后自动加载弹幕最多的来源并绑定到这部剧；数量相同时保持匹配顺序，不合并多个来源。
- 同剧后续集数优先沿用绑定来源，即使别的来源弹幕更多也不换源。只有绑定来源缺集、返回零弹幕或当前不可用时，才比较本集其他匹配来源、切到弹幕最多的来源，并在后续集数继续沿用新源。
- 所有来源都无法完成时才发 Windows 通知，点击通知可打开工作台手动搜索或换源。整体自动任务限时 60 秒；超时不会把未完成比较的部分结果当成最终选择。
- 未配置 API、没有搜索结果或无法可靠匹配当前分集时也会通知。重复播放状态不会重复搜索、反复通知。Windows 免打扰可能隐藏通知，工作台仍保留失败提示。
- 手动搜索、加载或取消后，当前视频暂由你接管，下次切换视频恢复自动匹配。API 地址不会因自动匹配而写入配置文件。
- “已连接桌面宿主”只表示工作台连接成功。只有播放状态明确显示自动同步时，才代表读到了当前播放器的有效信号。

## 调整显示

- 首次启动默认字号22 px、文字描边0 px、滚动速度0.8×，关闭等比缩放；已有显示偏好继续保留。
- 1/4、1/2、3/4、全屏表示从视频客户区顶部向下的弹幕范围。
- 字号、等比缩放、速度、透明度、描边、密度、弹幕类型、去重和关键词过滤无需重新下载弹幕。
- 所有来源类型（包括原顶部、底部和逆向类型）统一从右边向左滚动，保持横向轨道。“来源类型”复选框只决定包含哪些来源类型。
- 首次加载和跳转后从当前时间继续，不再把前几秒历史弹幕成组补刷到屏幕。初次布局在准备完整后发布，避免逐行从上往下刷出。
- 跳转被确认时立即清空旧时间轴的活动弹幕、取消旧布局，再切换时钟，避免向后跳时旧弹幕先被新时间往右推、反复闪现。连续拖动只允许最终时间轴继续显示。
- 时间偏移的正值表示弹幕延后。先确认分集和来源正确，再小幅调整偏移。
- 工作台里的风景图是标注过的演示预览，不是播放器画面；真正弹幕显示在视频窗口上。点击其他窗口不会再隐藏弹幕；播放器最小化、隐藏或关闭时才隐藏覆盖层，恢复后继续显示。
- 当前覆盖层按播放器客户区定位，尚未承诺已精确排除黑边。

## 保存、错误与关闭

- 只有显示偏好会保存在本文件夹的 `.cache/app/preferences.json`，不保存 API 地址。WebView2 的本机资料也位于 `.cache`；不要把整个运行过的文件夹重新发给别人。
- 保存失败时界面会回滚或提示等待确认。出现“重新同步设置”时先执行该读取操作，不要反复点击提交。
- 服务读取超时会明确提示“请求超时”；检查连接后可重试。超时预算覆盖响应体读取，主动取消仍按取消处理。
- 读不到播放信号时，会显示未知、失联或手动状态；这不等于已自动同步。手动校时不能替代自动同步验收。
- 关闭工作台只收回托盘，弹幕和当前 API 会话继续运行。点击托盘图标可以重新打开；右键选择“退出弹幕伴侣”才会结束会话，不会关闭或控制爆米花播放器。
- 若文件检查失败，请重新解压完整 ZIP 到新文件夹。保留现有文件夹，便于核对问题；无需改变系统执行策略。

## 开机启动与托盘

- 工作台“启动与托盘”内有“开机自动启动”，默认关闭。主动开启后，下次登录 Windows 自动驻留托盘，不弹主窗体；不需要管理员权限。
- 关闭该选项会移除本程序在当前用户启动文件夹中的快捷方式。移动或删除文件夹、升级到新目录前，请先关闭旧版的选项，再从托盘退出旧版，最后在新目录重新开启。
- 单击托盘图标打开工作台，右键可以打开或退出。悬停查看当前剧集、弹幕来源和数量；长名称会截短，播放器尚未识别时显示等待状态。
- 开机启动不保存 API 地址；重启后仍需填写，或通过 `DANMU_API_BASE` 环境变量显式提供。若在 Windows 启动应用设置中另外禁用了程序，需要在系统内恢复。

## 试用时可能遇到的问题

- 暂停或继续播放时，弹幕可能稍晚跟上；第一次调整显示设置可能略有停顿。之前试用版的严格延迟指标尚未全部达标，本版没有将旧测量冒充新结果；是否影响观看，请以你的体验为准。
- 连续拖进度、换集/电影组合、多屏缩放和长时间运行还没有完成全面验证。如果出现弹幕错集、明显不同步、遮挡或卡顿，请直接反馈。

反馈时提供作品与集数、刚刚做了什么、期望和实际现象即可；能附截图更好，请遮住 API 地址和 Token。试用无需运行开发测试。完整验收指标仍保留在开发项目中，本次试用不代表这些指标已经全部通过。
