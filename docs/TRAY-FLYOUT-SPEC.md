# 托盘轻面板交互规格

日期：2026-10-29。状态：用户已确认，实施及验收结果另行记录。

基线：本公开源码目录的 `909fea1`，而不是外层旧 PowerShell 工作区。
沿用已确认的 `react-console`、`player-sync`、`danmaku-renderer` 模块边界，不新增服务或框架。
本文修订 `react-console` 的交互；视频内展示的提供方契约单列于 `VIDEO-OVERLAY-SPEC.md`。

## 目标与假设

- 将完整工作台改为随用随开的托盘设置面板，不再显示双栏页面、宣传标题或弹幕预览窗口。
- “首次搜索 try 3 次”解释为一次初始尝试加两次重试，共三轮，不是额外重试三轮。
- “最小化后还能看到”解释为需要消除的现状：视频最小化后，弹幕和搜索提示都必须隐藏。
- 默认宽度约 360 至 380 个逻辑像素；高度随版本、内容及可用工作区调整，不靠缩小文字塞入内容。
- 保留现有米白、深灰、黄色强调的视觉语言，降低装饰和留白，不引入字体、组件或运行时依赖。

## 主面板

顶部单独一条轻量工具栏，左上角依次为“弹幕”“开机启动”小开关；右侧仅保留收起入口。
开机启动必须保留现有显式操作、失败反馈及当前用户权限边界，不能打开面板时顺便启用。

内容自上而下，每项占一行：

```text
[弹幕 开关] [开机启动 开关]              [收起]
------------------------------------------------
API 地址   [已隐藏的地址输入框]           [保存]  仅普通版
显示区域   [1/4] [1/2] [3/4] [全屏]
弹幕字号   [-----------滑块----------]    22 px
滚动速度   [-----------滑块----------]    0.8x
不透明度   [-----------滑块----------]     90 %
文字描边   [-----------滑块----------]     0 px
等比缩放                                  [开关]
弹幕密度                              [标准 下拉]
更多设置                                      >
------------------------------------------------
当前剧集 / 当前状态              [手动搜索 / 换源]
```

- 示例数值仅展示排版；实际数值始终读取既有设置，不重置用户偏好。
- 普通 EXE 版本第一行显示 API 地址，保留显式保存、删除、当前用户加密存储及错误恢复；输入未保存不能悄悄切换服务。
- includeAPI 版本完全省略地址输入行，不用无用占位行补齐；服务启动或失败时使用一条精简状态，来源配置收入“更多设置”。
- 四个区域按钮保持从视频顶部向下的 1/4、1/2、3/4、全屏语义。
- 字号、速度、不透明度、描边统一为“标签 + 滑块 + 当前数值”，不使用多列设置卡片。
- “更多设置”承接类型过滤、去重、关键词、时间偏移、手动校时及 includeAPI 来源配置，不删除已有能力。
- 常规页面不常驻显示完整剧集介绍、搜索空状态、技术栈页脚或演示画面。

## 手动搜索与失败恢复

- 底部“手动搜索 / 换源”在同一个面板内切换到搜索页，不创建另一个完整窗口，也不在主设置下无限向下展开。
- 搜索页包含返回、片名输入和搜索、来源列表、分集选择和加载；优先带入当前播放器片名。
- 结果区可限高滚动，返回设置后保留同媒体下的查询和选中项，切换媒体后作废过期结果。
- 三级搜索、分集、下载仍使用真实 API 和现有媒体版本准入保护，不用演示数据冒充成功。
- 自动流程三轮均未成功后，视频提示手动搜索；托盘面板保留可恢复的失败状态和入口，不强行抢焦点。

## 托盘定位与收起

- 左键单击托盘图标打开；已经打开时再次单击收起。右键继续提供明确的退出菜单。
- 根据图标所在显示器、实际任务栏边缘和可用工作区定位，不硬编码主屏右下角。
- 任务栏在下方时向上滑入；在左方时向右上滑入；在右方时向左上滑入；在上方时向下滑入。
- 最终面板锚定托盘附近，边缘留有间隙；方向在屏幕空间不足时优先服从可见范围。
- 托盘折叠区、自动隐藏任务栏、多显示器及图标坐标暂不可用时，要有不越界的降级定位。
- 建议滑入约 160 至 200 ms，无回弹；系统减少动态效果时不依赖位移动画才能使用。
- 点击面板外部或按 Esc 收起；原生下拉、右键菜单、密码显示等内部交互不能被误判为点击外部。
- 收起不退出服务、不取消正常自动加载、不清除正在播放的弹幕；退出必须走显式退出路径。
- 隐藏后重开仍必须正确恢复 WebView2 可见性，不能重新引入已有的托盘打开白屏问题。

## 自动搜索的三轮策略

- 普通版和 includeAPI 版均适用，不将现有 includeAPI“最多比较三个候选来源”误当成网络重试。
- 每轮保留现有候选选择、当前分集匹配和同剧来源复用规则，不改变来源数量上限。
- 空结果、暂时网络错误或当前来源暂不可用，可在有限等待后进入下一轮；建议轮间等待 1 s、2 s。
- 三轮共享明确的总截止预算，保留现有请求超时；不能单纯把慢源最长等待乘三，也不能借重试移除超时保护。
- 地址为空、地址无效、身份认证失败等需用户修正的错误直接给出真实原因，不用无意义重试掩盖问题。
- 429 限流遵从服务重试提示和现有预算，不立即高频重打；无法在预算内恢复时提示稍后处理，不误称无弹幕。
- 只有当前媒体的整个操作仍有效时才能重试。换片、换集、换 API、进入手动处理或退出后，取消旧轮次、等待及迟到响应。
- 三轮内不重复发系统失败通知；最终失败至多给出一次非抢焦点提醒。成功后正常沿用同剧来源。

## 结构与风格

- `ui/src/App.tsx` 负责面板视图和可信连接，不负责逐帧绘字。
- `ui/src/components/` 保留显示设置、来源、API、启动选项等职责；组件重排不能绕开设置事务和消息校验。
- `desktop/native/Desktop.cs`、`DesktopTray.cs` 负责原生窗口生命周期和定位；`AutomaticMatch.cs` 负责有界重试及取消。
- 组件继续采用当前受控表单风格，例如 `onChange={e => update({ enabled: e.target.checked })}`，不添加绕过设置会话的第二份持久化状态。
- 所有开关、滑块、返回和图标按钮具备中文可访问名称、键盘操作和可见焦点。

## 测试与命令

在本源码目录运行，锁文件及工具链版本保持不变：

```powershell
npm.cmd --prefix ui test
npm.cmd --prefix ui run lint
npm.cmd --prefix ui run build
npm.cmd --prefix ui run test:e2e
$env:DOTNET_CLI_HOME = Join-Path (Get-Location) '.deps/dotnet-home'
.\.deps\dotnet\dotnet.exe run --project tests/NativeDistribution/NativeDistribution.csproj -c Release
```

- 单元回归：三轮上限、前两轮失败第三轮成功、取消等待、媒体/API 变化、永久错误、429 和总期限。
- 浏览器回归：无预览窗口、逐行设置、普通版/API 版差异、手动页往返、全部设置保留、错误/未知保存状态及窄宽度。
- 原生回归：任务栏四边、负坐标显示器、不同 DPI、收起/重开、内部菜单、正常退出和既有白屏保护。
- 实窗验收：任务栏位置对应的实际滑入、外部点击收起、视频遮挡/最小化、搜索提示与第一条弹幕；合成断言不替代这些观察。

## 边界与确认

- 必须：保留媒体身份、旧请求作废、样式兼容、API 加密与不泄漏、真实开机启动状态和正常退出清理。
- 需另行授权：改变依赖、启用真实用户开机启动、远程推送/发布、覆盖既有安装或历史发行产物。
- 禁止：为了通过测试删除断言、将加载数量当第一条已呈现、用纯 CSS 冒充原生托盘定位、修改外层旧工作区作为新 EXE 实现。
- 用户已确认本布局、“共三轮”和“最小化必须隐藏”；授权独立 worktree 开发，验证正常运行后合并 main。后续目标另行明确授权发布新 Beta、更新 README；不覆盖历史标签或附件。
