# 图标说明

![应用和托盘图标预览](assets/icon-preview.png)

配色参考网易爆米花官网公开图标中的亮黄和珊瑚红，图形采用本项目自己的电视、爆米花与弹幕构图：

- 没有天线和支撑脚的圆角电视外框表示视频播放。
- 屏幕内的爆米花桶对应播放器名称。
- 屏幕上方两排点线表示从右向左移动的弹幕。
- 托盘图标去掉大面积背景和细小装饰，保留电视、爆米花和弹幕线，兼顾 Windows 深浅色任务栏。

| 颜色 | 色值 | 用途 |
|---|---|---|
| 亮黄 | `#FFE56B` | 爆米花和弹幕点线 |
| 珊瑚红 | `#FF4962` | 电视框与爆米花桶 |
| 深紫 | `#2D2438` | 电视屏幕 |
| 奶油白 | `#FFF5D4` | 桶身和小图标点线 |

可编辑稿为 [应用 SVG](../assets/app.svg) 和 [托盘 SVG](../assets/tray.svg)。Windows ICO 各包含 16、20、24、32、40、48、64、128、256 px 九个尺寸；工作台和网页图标采用同一份应用 SVG。

开发环境安装 UI 固定依赖且已有 Microsoft Edge 后，可在项目根目录运行：

```text
node scripts/Build-Icons.mjs
```

此命令生成 `assets/app.ico`、`assets/tray.ico`、文档预览 PNG，并同步 `ui/public/favicon.svg`。生成后再构建 UI。普通用户使用 Release 内的现成图标，无需执行此命令。

配色参考入口：`https://bmh.163.com/`。本项目与网易爆米花没有官方隶属关系。
