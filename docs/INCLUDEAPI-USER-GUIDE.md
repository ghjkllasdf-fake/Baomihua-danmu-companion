# 爆米花弹幕伴侣 0.2.4 includeAPI

内置服务版会随伴侣自动启动本机弹幕服务，无需自己填写服务地址，也不用另装 Node、npm、.NET 或 PowerShell。请自行安装网易爆米花播放器并准备视频；搜索和获取弹幕仍需要联网。

## 安装和运行

- **安装版**：运行 `DanmuCompanion-0.2.4-win-x64-includeAPI-setup.exe`，选择当前用户可写的本地专用文件夹。开始菜单条目为“爆米花弹幕伴侣 includeAPI”。
- **免安装版（Portable）**：完整解压 `DanmuCompanion-0.2.4-win-x64-includeAPI-portable.zip`，运行 `DanmuCompanion.exe`；不要直接在压缩包中运行或只复制一个 EXE。

程序使用系统 WebView2 运行环境（最低 124）。缺少时安装版会联网安装；免安装版请先运行包内的 `MicrosoftEdgeWebview2Setup.exe`。下载包大小不等于解压后的占用空间；实际占用以包内文件为准，系统共享组件和个人缓存另计。

1. 打开伴侣，点击系统托盘图标展开面板，等待内置服务就绪。
2. 在爆米花中播放视频，伴侣会尝试搜索并加载弹幕。
3. 需要换源或选错分集时，点击面板底部的“手动搜索 / 换源”。

关闭面板只会将它收起；要完全退出，请在托盘菜单中选择退出。不要同时运行普通版与内置服务版，两版共享当前用户的显示设置。

## 显示和来源

托盘面板可调整显示区域、字号、速度、透明度、描边、阴影、缩放和密度。顶部弹幕固定显示；底部弹幕需要选择“全屏”并启用底部类型。关键词过滤、时间微调和手动校时位于“更多设置”。

兼容的播放器窗口在控制栏出现时会显示弹幕开关和快捷设置按钮；鼠标移到设置按钮即可展开。无法识别控制栏时，这两个按钮不会出现，但仍可使用托盘面板。首次打开面板时，界面尚未就绪会先显示加载提示。

在“更多设置 → 选择弹幕来源”中可以勾选、排序和应用来源，至少保留一个。默认来源沿用上游：豆瓣、360、人人视频和韩剧TV。应用更改会重启内置服务；服务未就绪时可重试。多选来源不保证每个来源都有弹幕，上游限流、地区与网络情况也会影响结果。提示请求过多时请稍后再试。

电影弹幕较多时，首次加载可能需要等待。本机单次弹幕响应上限为 64 MiB，一次自动匹配最多等待 180 秒；超时后会停止，不会一直重试。

多季作品缺少可靠季数信息时，需要手动选片／选集。部分播放器首次同步可能需要等待；无法直接获知倍速时，首次同步可能约需 10 秒，之后的倍速变化也可能不会立即生效。伴侣不会修改字幕内容或播放器设置。

## 更新与卸载

“更多设置 → 软件更新”可以按每天、每周或每月检查新版，也可手动检查；发现新版后需自行下载，程序不会自动安装或替换文件。更新或切换版本前请从托盘退出伴侣。

安装版通常安装到原目录；要更换目录时先卸载旧版。免安装版请完整解压到新文件夹。安装版会覆盖安装清单内的同名程序文件，请不要在这些位置放置个人文件。

卸载安装版请使用 Windows“已安装的应用”；免安装版退出后删除程序文件夹。个人设置和已选来源默认保留，安装目录中的额外文件也可能保留。移动或删除程序文件夹前，先关闭伴侣的开机启动，之后可按需重新开启。

## 数据与安全

内置服务只在本机运行，并使用临时地址和访问令牌；它不向局域网开放。实际搜索和获取弹幕会访问你启用的来源。来源偏好保存在 `%LOCALAPPDATA%\BaomihuaDanmuCompanion\app\embedded-api\sources.json`；普通版保存的服务地址不会被内置服务读取或覆盖。

若提示播放器以管理员身份运行，请保存操作并退出播放器，以普通方式重新打开，再从托盘退出并重启伴侣。不要将程序设置为永久管理员运行。若字幕交互无响应，可先退出外部自动化或调试工具，再重启播放器；既有字幕验收在未运行这类工具时完成，不代表已确认唯一原因或所有工具都存在问题。

应用和安装包尚未签名，Windows 可能提示未知发布者。请从项目发布页下载，必要时使用同版本 `SHA256SUMS.txt` 核对文件；校验值不能替代发布者签名。不要为运行程序关闭杀毒软件。Windows 10、所有播放器布局、多屏和长期播放环境并未全部验证。
