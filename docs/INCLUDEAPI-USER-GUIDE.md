# 爆米花弹幕伴侣 0.1.0-beta.3 includeAPI

这是额外提供的 Windows x64 测试版本：包含本机弹幕 API、私有 Node 运行库和自包含 .NET。启动伴侣时自动启动后台 API，并自动连接；不需要手动安装 Node、npm、PowerShell 或填写 API 地址。它不包含网易爆米花播放器、影视资源或离线弹幕库。

## 安装和运行

运行 `DanmuCompanion-0.1.0-beta.3-win-x64-includeAPI-setup.exe`，选择当前用户可写的本地专用空目录。开始菜单条目为“爆米花弹幕伴侣 includeAPI”。它使用独立安装登记，不覆盖 beta.2 普通安装版。Portable 则完整解压对应的 `includeAPI-portable.zip` 后运行 `DanmuCompanion.exe`，不要只复制单个 EXE。

仍然复用系统稳定版 WebView2（最低 124）。如缺少或过旧，安装器使用包内微软安装引导程序联网补装；Portable 用户先运行同目录 `MicrosoftEdgeWebview2Setup.exe`。不捆绑私有浏览器，也不保证缺少 WebView2 时完全离线启动。

此变体比约 200 MiB 的普通版更大，因为增加了 Node、完整上游 API 源码和生产依赖。下载文件是压缩体积；安装／解压大小见本候选版本随附的实测验证结果，不沿用普通版的 200 MiB 数字。

程序先驻留托盘，点击图标打开工作台。关闭窗口只是隐藏；使用托盘“退出”才会同时关闭伴侣和其拥有的 API 进程。不会注册 Windows 服务，不设置防火墙，不需要管理员权限。请先退出其他版本：不同副本仍共用当前用户显示偏好和单实例保护。

## 弹幕源

工作台显示本机服务状态，只提供来源启用／关闭、调整顺序、恢复默认和应用。默认来源沿用上游：豆瓣、360、人人视频、韩剧TV。至少保留一个来源；更改来源并应用会重启本机 API，并清除旧连接的请求与弹幕。未能启动时，可再次“应用”当前选择重试；不会后台无限重启。

自动匹配每轮最多随机尝试 3 个符合当前作品的候选来源，在实际尝试的候选中选弹幕最多者，不声称穷举所有来源。同剧绑定来源的尝试也计入本轮 3 个的预算；不足 3 个时只尝试实际存在的候选。搜索阶段仍使用所启用的上游搜索源。

保留上游缓存未命中的弹幕接口限流：每个 IP 每分钟 3 次。收到 HTTP 429 会停止本轮并提示稍后重试，不会继续换源冲击限制或进入无限重试队列。手动请求也受同一限制；来源可用性、地区限制和网络质量由上游平台决定，不保证每个来源都能返回弹幕。

## 本机服务和数据

API 只绑定 `127.0.0.1` 的临时端口，使用每次启动随机生成的访问令牌；地址不向界面展示、不写入旧 API 凭据文件。只开放健康检查和伴侣需要的搜索、分集、弹幕读取接口，不开放管理面板、代理、上传或局域网访问。浏览器跨站请求被拒绝。

本机 API 不等于不联网：实际搜索和获取弹幕需要向已启用的上游来源发出请求；启动和健康检查不会预取弹幕或主动访问来源。此最小版本不提供需要额外账号、Token、自定义 URL 或上传的来源设置。

来源偏好保存在：

```text
%LOCALAPPDATA%\BaomihuaDanmuCompanion\app\embedded-api\sources.json
```

原来的 `api.dat` 不被读取或覆盖，退回普通版后仍可使用原来保存的外部服务地址。显示偏好、浏览器数据位置与普通 Beta 相同。卸载只删除该安装拥有的程序文件和快捷方式，默认保留个人配置；Portable 退出后可删除程序文件夹。不要混合覆盖普通版、旧版或不同变体的文件。
