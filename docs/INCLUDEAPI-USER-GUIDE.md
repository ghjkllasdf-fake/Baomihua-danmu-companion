# 爆米花弹幕伴侣 0.2.1 includeAPI

**0.2.1 正式版候选（未发布）**：拟修复倍速播放时弹幕消失或闪现，以及流光玻璃皮肤圆角显示。真实播放和最终发行包验收尚未完成，两项修复效果待证实；不据此承诺所有系统或 DPI 环境。 包名及下载地址为发布计划；在验收完成并公开发布前，不表示已有可用安装包。

0.2 正式版与普通版同步，保留 GitHub 新版本提醒，可选择每天／每周／每月检查，发现新版后打开 Release 页面自行下载；不提供在线下载安装替换。新发行包的语言资源仅保留中文和英语；原位升级的旧语言文件卸载时才清理，不会立即释放这部分空间。右上角衣服图标可切换四套皮肤，外观自动保存；系统不支持透明效果时使用实色底。

这是额外提供的 Windows x64 版本：包含本机弹幕 API、私有 Node 运行库和自包含 .NET。启动伴侣时自动启动后台 API，并自动连接；不需要手动安装 Node、npm、PowerShell 或填写 API 地址。它不包含网易爆米花播放器、影视资源或离线弹幕库。

全新配置默认使用第一款皮肤、0.6 倍弹幕速度、100% 不透明度、零描边、100% 阴影，开启等比缩放并使用密集弹幕；已有保存偏好不会被覆盖。

本机服务不再限制每分钟弹幕拉取次数；上游平台限流、请求超时及并发上限仍保留。

## 安装和运行

运行 `DanmuCompanion-0.2.1-win-x64-includeAPI-setup.exe`，选择当前用户可写的本地专用目录（建议使用默认位置）。开始菜单条目为“爆米花弹幕伴侣 includeAPI”。它使用独立安装登记，不覆盖普通安装版。Portable 则完整解压对应的 `includeAPI-portable.zip` 后运行 `DanmuCompanion.exe`，不要只复制单个 EXE；无需额外准备即可检查新版。

仍然复用系统稳定版 WebView2（最低 124）。如缺少或过旧，安装器使用包内微软安装引导程序联网补装；Portable 用户先运行同目录 `MicrosoftEdgeWebview2Setup.exe`。不捆绑私有浏览器，也不保证缺少 WebView2 时完全离线启动。

此变体额外包含 Node、完整上游 API 源码和生产依赖，不套用普通版体积。实际安装／解压大小以同版本文件清单为准。下载文件是压缩体积；包内 `manifest.json` 列出实际程序文件和长度，安装器还会添加卸载文件。系统共享 WebView2 和运行后产生的个人缓存另计。

程序先驻留托盘，点击图标展开／收起轻面板，点击外部或按 Esc 也只收起。左上角是弹幕、开机启动开关（默认关闭）；逐行设置区域、字号、速度、不透明度、描边、阴影、缩放和密度。顶部弹幕固定显示；底部弹幕仅在选择“全屏”显示区域且启用底部类型时显示。底部“手动搜索 / 换源”在同一面板内选片、选集。没有预览窗口。关闭窗口只是隐藏；使用托盘“退出”才会同时关闭伴侣和其拥有的 API 进程。不会注册 Windows 服务，不设置防火墙，不需要管理员权限。请先退出其他版本：不同副本仍共用当前用户显示偏好和单实例保护。

## 弹幕源

主面板不显示 API 地址输入；“更多设置”显示本机服务状态和“选择弹幕来源”，提供来源启用／关闭、全选、全不选、调整顺序、恢复默认和应用。默认来源沿用上游：豆瓣、360、人人视频、韩剧TV。至少保留一个来源；“全不选”只清空待应用的选择，不会立即关闭服务，空选择不能提交。更改来源并点击“应用来源”会重启本机 API，并清除旧连接的请求与弹幕。未能启动时，可再次“应用”当前选择重试；不会后台无限重启。

自动匹配每轮最多随机尝试 3 个符合当前作品的候选来源，在实际尝试的候选中选弹幕最多者，不声称穷举所有来源。同剧绑定来源的尝试也计入本轮 3 个的预算；不足 3 个时只尝试实际存在的候选。搜索阶段仍使用所启用的上游搜索源。

多季剧先核对当前季数，兼容“第二季”“第2季”“S02E02”和常见数字续季名称。其他季在抽样前排除，不占本轮3个候选的预算；同季后续沿用来源，跨季则重新绑定。窗口省略季数时，可只读使用爆米花已有首页、最近观看相册缓存或详情页的当前媒体信息，不要求先手动选源。信息缺失或相互冲突时停止并提示处理，不默认猜第一季。

季数核对不修改播放器缓存、不解析凭据端点或解密数据库，不上传文件路径或缓存，也不新增观看历史保存。同一播放窗口按顺序连播可沿用已核实季数，跳集或更换媒体会重新核对。

0.2 的本机服务通过 `RATE_LIMIT_MAX_REQUESTS=0` 取消本地每分钟弹幕拉取次数限制，自动和手动加载均适用。上游平台仍可能限流；收到 HTTP 429 会停止本轮并提示稍后重试，不会继续换源冲击限制或无限重试。来源可用性、地区限制和网络质量由上游平台决定，不保证每个来源都能返回弹幕。

电影的完整弹幕可能较大，首次载入需要等待。本机单次响应最多 64 MiB、请求最多 180 秒，自动匹配的最多三轮共用 180 秒总预算，轮间等待 1 秒、2 秒；超时会停止并提示，不会把截止时间乘三或无限循环。调整来源只能改变取数来源，不会绕过上游限制或扩大响应大小、超时和并发边界。

视频右上角显示搜索／装载提示，首条当前弹幕实际呈现后渐隐；失败提示倒计时五秒后渐隐。提示与弹幕均伴随视频：普通窗口遮住视频时也遮住弹幕，最小化、隐藏或关闭后桌面不再可见。

## 本机服务和数据

### 软件更新

“更多设置”和底部折叠的“软件更新”以同款红色“新”角标提示新版。默认每天检查，可选每周或每月（30 天），也可关闭自动检查后手动检查。点击“查看 Release”打开本项目发布页面，自行下载 includeAPI 的对应安装版或 Portable 包。

伴侣只读取 GitHub 版本信息，不下载更新包，不替换程序，不自动重启或清理旧目录；不会改变远端服务或控制播放器。升级前请从托盘退出伴侣，安装版运行完整安装包，Portable 完整解压到新文件夹；个人设置和已选来源无需清除。安装中断或文件冲突时的处理见 [安装与升级说明](BETA-USER-GUIDE.md)，不要强行覆盖外来文件。

API 只绑定 `127.0.0.1` 的临时端口，使用每次启动随机生成的访问令牌；地址不向界面展示、不写入旧 API 凭据文件。只开放健康检查和伴侣需要的搜索、分集、弹幕读取接口，不开放管理面板、代理、上传或局域网访问。浏览器跨站请求被拒绝。

本机 API 不等于不联网：实际搜索和获取弹幕需要向已启用的上游来源发出请求；启动和健康检查不会预取弹幕或主动访问来源。此最小版本不提供需要额外账号、Token、自定义 URL 或上传的来源设置。

来源偏好保存在：

```text
%LOCALAPPDATA%\BaomihuaDanmuCompanion\app\embedded-api\sources.json
```

原来的 `api.dat` 不被读取或覆盖，退回普通版后仍可使用原来保存的外部服务地址。显示偏好、浏览器数据位置与普通版相同。卸载删除安装日志列出的程序文件（含同名替换文件）和快捷方式，默认保留个人配置；同名私人文件由用户自行负责。Portable 退出后可删除程序文件夹。不要混合覆盖普通版、旧版或不同变体的文件。
