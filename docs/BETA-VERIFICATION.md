`scripts/test-release.mjs` 对上述文件运行，10 组交付检查全部通过：

- 核对两个最终文件的 SHA256；校验 ZIP 全部清单和实际字节，检查包内白名单及已知本机目录泄漏。
- 完整解压后移动到中文／空格目录，实际运行 EXE；不从构建输出目录替代 Portable 验收。

- 实际静默安装到中文／空格自定义目录；核对安装文件、卸载登记以及开始菜单快捷方式直接指向 EXE。

- 实际卸载后主程序、开始菜单快捷方式和卸载登记消失；隔离数据与外来文件仍保留。
- 成功测试的临时安装目录已清理；测试没有使用实际用户的 API、浏览器资料或偏好。

## 回归与审查

- 原生分发：86 项计数断言，另通过原有协议／帧、操作、事件、Job 清理、监控、自动匹配和 API 超时夹具。
- 实际 Inno 测试：20 个场景，覆盖空／非空目录、安装所有权、盘根、UNC／映射网络盘、升级冲突和真实目录联接／外部哨兵。
- 前端：lint、类型／生产构建、145 项单元测试、45 项浏览器 E2E 通过。
- 分发／归档／源码稳定性：7 项 Node 测试通过；删除 PowerShell 依赖排除条件的独立突变被测试捕获。
- 隐私工具：9 项测试通过；源码索引检查通过。Inno 的精确系统 DLL 导入语法不再误判为邮箱，邻近非占位邮箱仍被拒绝。
- 固定 UI 锁文件的 npm 审计：本次为 0 个已知漏洞；这不是对所有原生组件和操作系统的穷尽漏洞认证。
- 独立代码复核中的目录覆盖、旧自启动、网络盘、锁定构建、重解析点及路径尾部分隔符问题均已处理。

## 保留边界

- Windows 10 尚未进行完整操作系统验收；其专用浏览器首次启动需要在自有目录设置沙箱读取／执行权限，不承诺只读介质。
- 不支持网络共享及映射网络盘运行；ARM64 未验证。
- 长期真实播放、多屏 DPI、全部焦点组合以及既有严格延迟指标仍未全部验收；演示画面和打包检查不能替代这些结果。
- 未访问用户的真实弹幕服务验证内容；搜索和下载仍需用户自行准备可达、兼容的服务。
- 不包含 GitHub 发布、推送、打 tag 或证书购买。
