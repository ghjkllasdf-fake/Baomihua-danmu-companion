# 视频内弹幕与搜索提示规格

日期：2026-10-29。状态：用户已确认，实施及验收结果另行记录。

本规格修订既有 `danmaku-renderer` 的窗口展示契约，依赖 `player-sync` 的只读窗口与媒体快照。
搜索状态由 `react-console` 所属的原生匹配流程提供，不由 React 页面开关决定。
托盘面板关闭时，自动搜索、视频状态提示和弹幕仍须正常工作。

## 目标

弹幕及状态提示都是当前视频的附属内容，不是覆盖整个桌面的全局置顶字幕。
最小化、隐藏、关闭、窗口身份变化或可信视频窗口丢失时，都不留可见残影。

## 视频右上角状态

| 阶段 | 可见文案 | 结束条件 |
| --- | --- | --- |
| 正在搜索 | 搜索弹幕源，可附当前第几轮 | 当前媒体搜索转入装载或终态 |
| 取得可用来源并装载 | 已发现弹幕，进行装载 | 当前媒体第一条弹幕实际呈现后渐隐 |
| 三轮搜索仍无结果 | 未找到弹幕，可手动搜索，附 5 s 倒计时 | 倒计时结束后渐隐 |
| 网络、认证或限流等错误 | 简短真实原因及可恢复方式 | 倒计时后渐隐，完整原因保留在托盘面板 |

- 提示位于视频右上角留边区域，不改变弹幕轨道，不抢焦点，不拦截视频鼠标操作。
- 无弹幕内容时也能显示搜索/失败提示；不能继续用“必须已加载弹幕”作为提示可见的前提。
- HTTP 完成、弹幕解析完成、队列非空、`activeCount > 0` 都不是第一条实际呈现的充分证据。
- 第一次呈现信号必须来自当前媒体、当前弹幕加载代际及可见视频内的真实渲染路径。旧媒体信号不能关闭新媒体提示。
- 视频暂停或关闭弹幕导致没有第一条时，不伪造呈现完成；保留真实装载状态，视频或弹幕被隐藏时一并隐藏提示。
- 失败倒计时使用单调时间，不逐秒累积 UI 定时器漂移；同一阶段重复推送不能不停重置 5 s。
- 渐隐建议约 250 至 350 ms，取消、换片和失效窗口立即清除；减少动态效果时直接结束可见状态。
- 关弹幕开关时，视频上的弹幕与辅助提示一起隐藏；错误仍可从托盘查看。

## 窗口归属与层级

- 绑定经过验证的目标视频 HWND、进程身份、当前媒体及窗口几何，不能因为旧 HWND 仍非零就继续显示。
- 不使用与播放器无关的全局永久置顶来保证可见。具体原生策略须通过真实跨进程播放器的窗口/全屏兼容性验证，不在设计阶段把设置 Owner 或 SetParent 当已证明方案。
- 播放器可见但不是前台时，未被遮挡的区域仍可显示弹幕；普通其他窗口压在播放器上方时，弹幕和提示不能反过来压住该窗口。
- 最小化、隐藏或关闭视频时，弹幕和提示都隐藏；恢复时按当前真实进度重建，不补播隐藏期间弹幕，不短显旧媒体。
- 移动、缩放、切换全屏、切换显示器和 DPI 后，位置及裁剪跟随视频目标，不漂到桌面其他位置。
- 当前仅有播放器客户区几何，不能冒称已检测到真实影片内容矩形。若黑边或播放器栏范围需要进一步收紧，须另行证明内容边界。
- 保持鼠标穿透、无焦点激活、独立渲染线程、队列和位图内存预算，不为状态提示新增全局置顶通知窗口。

## 结构与接口边界

- `desktop/native/Overlay.cs` 的渲染与可见性控制负责弹幕/提示的一致生命周期。
- `OverlayPresentation.cs`、`Windows.cs` 负责窗口呈现和层级；不得在高频绘制中引入播放器 UI Automation 遍历。
- 搜索流程提供匹配代际和真实阶段；渲染器提供当前代际的首次可见呈现反馈。接口必须保留可取消和旧代际作废语义。
- 不为提示添加桌面任意执行、文件或通用跨进程控制能力。

## 测试与命令

在公开源码目录保持固定工具链运行：

```powershell
$env:DOTNET_CLI_HOME = Join-Path (Get-Location) '.deps/dotnet-home'
.\.deps\dotnet\dotnet.exe run --project tests/NativeDistribution/NativeDistribution.csproj -c Release
```

- 首先增加失败回归：无弹幕时提示可见、下载完成不能提前消失、当前代际首次呈现后渐隐、五秒失败倒计时及重复状态不续命。
- 覆盖关弹幕、暂停、最小化/恢复、换集、切 API、手动加载、旧首次呈现反馈、取消和退出。
- 实窗验证其他普通窗口遮挡视频时不会被弹幕/提示压住，未遮挡视频仍显示，最小化后桌面没有残留。
- 保留已有 seek 清旧、背景可见、透明、穿透、无激活和资源预算测试；不能靠全部改成“失焦就隐藏”绕过窗口层级问题。
- 真播放器窗口/全屏和多 DPI 需独立验收；无法操控前台或缺少对应设备时保留未验证状态，不降低门槛。

## 边界与确认

- 必须：真实媒体身份、当前代际呈现证据、所有提示和弹幕共同隐藏、正常退出释放。
- 已确认：视频最小化后不应再看到弹幕，弹幕和视频窗口伴生。
- 禁止：将全局置顶加定时 Hide 当作窗口归属已完成，或用下载完成/模拟弹幕冒充真实首条呈现验收。
