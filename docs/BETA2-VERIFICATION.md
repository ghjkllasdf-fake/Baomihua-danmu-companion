## WebView2 前置条件

- 复用系统稳定版 WebView2 Evergreen Runtime，最低主版本 124；不捆绑私有浏览器，因此程序本体保持约 200 MiB。
- 最终启动测试实际使用共享 Runtime `156.0.4314.50`，浏览器进程位于系统的 `Microsoft/EdgeWebView/Application/<version>/` 目录。
- 包含微软原始 Evergreen 安装引导程序 `MicrosoftEdgeWebview2Setup.exe`：版本 `1.3.307.15`、1889488 字节、SHA256 `13f6d9cdc8c3e7186e4b180db7f48e199ee97d631480e8391fb3106f338fb21a`；本次 Authenticode 检查为有效，发布者为 Microsoft Corporation。
- 安装版只在 Runtime 缺失或过旧时运行引导程序联网补装，失败则停止应用安装。Portable 缺少 Runtime 时提示用户手动运行引导程序；不承诺在无 Runtime 的电脑上完全离线启动。
- 缺失／旧版检测和引导程序失败通过隔离测试覆盖，没有卸载、破坏或替换验收机器的真实共享 Runtime 来制造条件。未完成一台全新、无 Runtime 操作系统上的联网补装验收。
- 应用显式请求稳定通道并清理继承的浏览器、调试和资料目录覆盖；受管电脑的 WebView2 注册表策略仍可能影响 SDK 选择，此类环境未验证。
- 精简版不修改共享 Runtime 目录权限，卸载应用也不删除共享 Runtime。

## 迁移与保留边界

- 安装器和原创 EXE **未做代码签名**；微软引导程序的签名不等于本应用已签名。Windows 可能提示未知发布者，不应因此关闭杀毒软件。`SHA256SUMS.txt` 只检查一致性，不能证明发布者身份。
- 从 preview.15 脚本版迁移时先退出旧实例；曾启用旧开机启动的，在 Beta 中关闭后再按需开启，即切换为直接 EXE 启动。API 与显示偏好迁移细节见 `BETA-USER-GUIDE.md`。
- 从本地 beta.1 完整离线安装版迁移时，先卸载旧安装；Portable 解压到新空目录。不要混合旧私有 `WebView2Runtime` 或不同版本依赖。
- 本次实际操作系统验收仅覆盖 Windows 11 x64 build 26300；Windows 10 尚未完整验收，ARM64 未验证，不支持网络共享及映射网络盘运行。
- 长期真实播放、多屏 DPI、全部焦点组合和既有严格延迟指标仍未全部验收；打包检查和握手不能代替这些结果。
- 搜索与下载真实弹幕需要用户自行提供可达、兼容且可信的服务，本项目不提供公共 API、账号、Token 或影视资源。
- 如需回退，先退出 Beta，关闭其开机启动，卸载安装版或改用独立的旧版目录；保留个人配置备份，不混合覆盖运行库。共享浏览器资料使用新的 `webview-evergreen` 目录，不复用 beta.1 私有浏览器资料。

公开复核命令见 `DEVELOPMENT.md`。本机原始日志含开发目录，仅保留在忽略的构建／验收目录内，不作为公共发布附件。
