# Beta4 托盘轻面板验证记录

日期：2026-10-29。基线：`909fea1`。本记录区分源代码回归、受控实窗、演示截图和最终发行包，不把其中一项冒充其他项。

## 实现范围

- 约 380 × 540 逻辑像素的无边框托盘面板，不显示任务栏主窗口，不再渲染产品预览窗口。
- 图标所在显示器及任务栏边缘决定定位和滑入方向；四边、负坐标、空间不足和自动隐藏降级由确定性测试覆盖。
- 逐行设置、左上角小开关、同面板内搜索／更多设置，保留原设置事务、API 显式加密保存及默认关闭的开机启动。
- 首次自动匹配最多共三轮，保留总期限、候选数限制、取消／媒体代际保护；认证失败和 429 不盲目重试。
- 视频右上角状态由原生渲染器绘制，当前加载代际的首条可见弹幕才完成装载提示；失败倒计时五秒。关闭系统客户区动画时无渐隐尾部。
- 视频窗口身份须同时匹配 HWND、采样 PID 和标题；覆盖层紧随视频 Z 顺序，其他窗口可以遮挡，最小化／隐藏／销毁时隐藏。不跨进程设置父子关系。

## 设计收尾

采用 `design-taste-frontend` 的 app-screens 流程。所选方向为 `achromatic-ledger`，seed `675484666`，保留既有 palette/type；没有重新抽取方向。产品自身的脸是爆米花已有米白／黄色和离线中文字体，特征元素是从视频顶部向下的四档区域选择，而非仪表盘卡片。

本屏首先回答“怎样快速调整当前视频的弹幕”；来源页回答“当前片名要加载哪个来源和分集”。常用操作一层可达，错误不藏在折叠区。

收尾修正了渐变装饰、保存按钮禁用态对比度、15px 不一致边距、过小的主标签、重复等待信息及不明确的导航焦点。主控件和数值为 13px，次要说明 11–12px，无低于 11px 的文字；数值右对齐并使用等宽数字。补充了高级时间偏移长标签不换行的失败回归后修正列宽，搜索页滚动时保留返回导航。

源检查结果为 0 FAIL、0 WARN。最终浏览器 inspector 在 1440、768、390 三个宽度得到 0 FAIL、3 WARN，六张输出截图均逐张查看，允许项如下：

- `palette-cream`：保留已经确认的现有品牌配色，而不是引入新配色。
- `hero-void`：浏览器画布比 380 × 540 的原生组件大；空白位于组件外，不是把原生窗口做成整页。
- `tiny-text`：11–12px 仅用于次级状态和说明；设置标签和数值均为 13px，不能继续缩字塞内容。

截图复核：边缘对齐、四个区域按钮等宽、滑块值同列；缺失进度不伪造时钟；无图表／KPI／合计，因而不存在凭空统计。390px 触控模式加大命中区域后允许主区滚动，固定底部入口不覆盖主区内容；没有页面级横向溢出。320／380px 另由浏览器回归验证。

README 四张托盘图由 `scripts/Capture-TrayScreenshots.mjs` 使用真实 React 组件和隔离示例 bridge 生成，均标有“界面演示”。示例地址、作品和分集不是实际联网结果。旧视频效果图仍只是自制动画与原生示例弹幕叠合，不是本版播放器验收证据。

## 最终发行门槛

本记录的源代码测试不是最终安装包验收。维护者仍须从干净的同一提交生成普通版、includeAPI 和 corresponding-source，执行 `scripts/test-release.mjs` 两个变体的最终字节验证，再核对公开附件的下载 SHA256。最终字节报告保留在本地忽略的 `artifacts/beta4/`，不得上传完整机器日志或真实配置。

安装测试遇到既有用户安装或同名开始菜单目录时必须停止，不能覆盖或卸载用户软件。发布使用新 tag／新 prerelease，不覆盖 Beta3 及其附件。回退时退出 Beta4，再使用保留的 Beta3 对应变体和原配置；跨目录开机启动仍须先关闭旧入口再显式开启。

## 保留的限制

- 15 秒、5 万条、1920 × 1080 的同条件合成压力运行中，基线最高活动数 90，本版快照 91，均未达到 100。基线回调间隔 p95/p99 为 16.33/17.32ms，本版为 15.89/17.39ms；这不是物理显示帧率，也不是 60 秒完整压力目标通过。原断言和门槛保留。
- 尚未完成真实爆米花全屏／长期观看、任务栏四边的逐一物理操作、多显示器 DPI 矩阵、Windows 10 完整兼容及严格端到端延迟验收。受控窗口测试不能替代这些。
- 覆盖层目前按播放器客户区定位，可能包括黑边；没有声称已识别实际影片内容矩形。
- 没有重新宣称完成整个 bridge/settings 安全审计。既有推送设置冲突未撤销全桥信任、断连后旧 includeAPI 就绪文字可能暂留，仍属独立问题；断连控制被禁用，本记录不声称断连写入成功。
