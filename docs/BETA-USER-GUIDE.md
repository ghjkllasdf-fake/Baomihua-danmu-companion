# 爆米花弹幕伴侣 0.1.1-beta.7（托盘轻面板）

Beta7 新增 GitHub 自动更新和每天／每周／每月检查，更新采用无备份的原位覆盖，并精简为中文和英语资源。保留四套皮肤、多季匹配和播放同步。

右上角衣服图标可以切换原生清爽、流光玻璃、WinUI、石墨工作室，选择会自动保存。透明效果受 Windows 支持和设置影响；开启“减少透明效果”后使用实色底。自动匹配最终失败时，底部“手动搜索 / 换源”以柔和呼吸灯提示“需处理”；关闭系统动态效果时保留静态提示。

本版提供 Windows x64 安装版和 Portable 版。主程序、后台播放器采样和开机启动均直接使用 EXE，不再调用 PowerShell，不需要调整执行策略。

程序随附的 .NET 语言资源只保留中文简／繁体及英语默认资源，不修改系统或共享 WebView2。原位升级仅清理可证明归属的旧语言资源；被替换、占用的文件和外来文件保留，不按目录名称强制删除。

两版均包含 .NET 10.0.14，不需要另装 Node、npm、.NET SDK 或 .NET Runtime；改为复用系统的稳定版 WebView2 Evergreen Runtime（124 或更新版本），不再捆绑约 673 MiB 的私有浏览器。程序安装／解压大小约 200 MiB，下载包是压缩体积，会更小。请完整保留包内 DLL 和资源，“EXE 程序”不等于只复制一个 EXE。

Windows 11 通常已有 WebView2，大多数 Windows 10 也已安装。没有或版本过旧时需要联网安装／更新：包内 `MicrosoftEdgeWebview2Setup.exe` 是微软签名的原始安装引导程序，不是 PowerShell。只安装了 Edge 浏览器不能代替 WebView2 Runtime。

## 安装版

1. 运行 `DanmuCompanion-0.1.1-beta.7-win-x64-setup.exe`。
2. 阅读原创程序 MIT 许可和包内 Microsoft WebView2 的独立许可条款。
3. 在“选择目标位置”页面指定安装文件夹。可以选择其他本地磁盘及包含中文、空格的路径；请选择当前账户可写的专用子目录，不要选择磁盘根目录或网络共享。
4. 已有合适的 WebView2 时直接复用；没有时安装器会运行微软引导程序联网补装并再次检测，失败会停止应用安装。完成后从开始菜单打开“爆米花弹幕伴侣”。桌面快捷方式可选，开机启动不会自动开启。

默认安装到当前用户的本地程序目录，不需要提升管理员权限。不能写入选定位置时，应改选可写位置，不要因此关闭系统安全功能。

安装器会拒绝非空的无关文件夹和 Portable 目录；本程序已登记的完整原安装目录可原位重装，存在本版受控中断记录时也可进行校验修复。全新安装请选择空的专用文件夹，不要用安装器转换 Portable。

## Portable 版

完整解压 `DanmuCompanion-0.1.1-beta.7-win-x64-portable.zip` 到本地文件夹，然后双击 `DanmuCompanion.exe`。不要在压缩软件中直接运行，也不要只取出一个 EXE。

Portable 不为应用创建安装记录；**已有 WebView2 时解压即用**。缺少时会明确提示，请先手动运行同目录 `MicrosoftEdgeWebview2Setup.exe` 联网安装／更新，再打开主程序。这个精简版不承诺在没有 WebView2 的电脑上完全离线、零前置环境启动。微软运行库自己的安装登记不属于应用 Portable 安装记录。

移动整个文件夹后仍可使用；如果曾手动开启开机启动，移动前先关闭，移动后再开启。请选择本地专用目录，不支持网络共享或映射网络盘。精简版不修改系统 WebView2 目录的权限，也不会在退出或卸载时删除共享浏览器。

## 开始使用

- 启动后先驻留系统托盘，点击图标打开面板；关闭面板只是隐藏，退出请使用托盘菜单。
- 自行安装网易爆米花播放器，并准备兼容弹弹play API v2 的弹幕服务地址。本程序不提供影视资源、弹幕库、公共 API 或 Token。
- 在面板顶部填写地址并点击“保存地址”。搜索、分集和弹幕请求会发往你指定的服务，请只使用可信服务。
- 面板左上角是弹幕和开机启动开关；开机启动默认关闭。普通版首行为 API，随后逐行调整区域、字号、速度、不透明度、描边、阴影强度、等比缩放和密度。阴影默认 45%，调到 0 关闭；阴影与描边分别调节，整体跟随不透明度和视频等比缩放。过滤、关键词、时间偏移和手动校时在“更多设置”。
- 底部“手动搜索 / 换源”在同一面板内打开来源和分集选择，返回后保留当前作品的输入；换片后清除过期来源。不再有预览窗口。
- 点击托盘图标切换展开／收起，点击外部、按 Esc 或点“收起”均不退出。下方任务栏向上滑入，左侧向右上、右侧向左上、顶部向下；关闭系统动画时直接展开。
- 首次匹配最多共三轮，轮间等待 1 秒、2 秒，共用普通版 60 秒总预算。认证失败、限流或无效地址直接提示，不反复请求；失败后使用手动搜索。
- 视频右上角显示“搜索弹幕源”“已发现弹幕，进行装载”；当前内容的首条弹幕实际出现后渐隐。最终失败提示五秒后渐隐，完整状态保留在面板。
- 弹幕及提示跟随视频的窗口层级，其他窗口可以遮住它们；视频最小化、隐藏或关闭后共同隐藏，不留在整个桌面最前端。
- 自动匹配、同剧来源绑定和暂停／跳转同步保留；未知播放器信息仍明确显示未知，不冒充自动同步。
- 多季剧会核对当前季数，按季搜索和沿用来源；支持中文季名、Season、SxxExx 等常见写法。播放窗口没有季数时，只读核对爆米花已有首页缓存或详情页的当前媒体信息，最近观看入口也可使用。信息冲突时提示手动处理，不把其他季弹幕误载到当前季。

季数核对不会修改播放器缓存、不解析凭据端点、不解密数据库，不会把文件路径或缓存发往弹幕服务，也不新增观看历史保存。同一播放窗口按顺序连播可沿用已核实季数，跳集或更换媒体会重新核对。

## 配置、升级和卸载

### 软件更新

此功能从 Beta7 开始提供；已发布的 Beta6 附件不变，Beta6 用户需要先手动安装一次 Beta7。

“更多设置”右上角出现红色“新”角标时，可展开页面最下方的“软件更新”；模块标题会显示相同角标，平时可单独收起。

默认每天检查 GitHub，可改为每周或每月；每月按 30 天计算。关闭自动检查后仍可手动检查。自动下载默认关闭，检查不会退出程序或控制播放器。Beta 通道接收 Beta 和正式版，正式版通道只接收正式版，不会降级或改变普通版／includeAPI、安装版／Portable 类型。

下载通过 SHA-256 校验后，先点击“重启并更新”，再确认，才会退出并更新伴侣。API、显示和外观偏好保留；不覆盖外来文件。校验失败或文件冲突不会强行安装。更新组件与主程序共用同一套 .NET 运行库，不捆绑第二套浏览器。

更新包通过 SHA256、文件清单、版本和发行版校验后，在原安装／解压目录直接覆盖，随后启动新版并验证界面、采样和必要服务。不会创建旧版本备份，不提供自动回滚或恢复旧版入口；个人设置及与程序无关的文件保留。

安装版的自动更新会同时下载对应安装器和校验过的配套 ZIP，用于安全放入新增文件；因此下载量比单独手动下载安装器更大，进度按两份附件的合计字节显示。Portable 只下载对应 ZIP。

自定义数据目录过长时，更新组件会在退出原程序前拒绝启动；可改用较短的数据目录或手动安装。卸载时若新增文件被占用或被其他文件替换，会保留文件及程序目录旁的身份登记，请检查后再清理，不要删除不明文件。

若更新已开始覆盖后中断，或新版启动验证失败，请先退出伴侣。安装版使用同版本完整安装器安装到原位置修复；修复只接受原操作记录的文件哈希和磁盘身份，与外来文件冲突时会停止。Portable 则将同版本完整 ZIP 解压到新的空目录运行，并保留原目录；不要混合覆盖文件，也不要用安装器修复 Portable 目录。正常当前用户配置可继续使用。若只是写入前校验失败，原程序文件未变，可继续使用旧版。历史旧版备份不会被批量删除或用于恢复新版。

Beta7 起登记全部程序文件及清单的磁盘身份；登记缺失、不完整或被替换时，不会按当前字节重新信任文件。新解压的 Portable 首次正常启动会校验完整包并登记初始身份，未完成的初始登记不会自动重试覆盖；登记失效只停用更新，不妨碍其余界面使用。移动已登记的 Portable 后，请改用新空目录完整解压版。Beta6 及更早版本首次迁移没有历史磁盘身份，只能以完整文件清单校验建立初始登记，无法据此证明迁移前同字节文件的历史归属。初始登记基于用户信任的完整包，不是发布者签名；删除所有历史登记后，系统不能可靠区分首次使用和人为清除历史。

文件身份登记缺失／损坏但没有受控的中断操作记录时，不能靠原位重装重新认领文件。请保留原目录；安装版先卸载安装登记，再安装到新的空目录，Portable 将完整 ZIP 解压到新的空目录。登记元数据属于本用户可写的数据，不具备独立防篡改认证；不要手工重写文件身份或校验值，也不要把 SHA256 清单当作发布者签名。

更新目录的创建记录也必须完整；若在创建目录与登记落盘之间断电或结束更新进程，残留目录无法证明归属，修复会停止而不是重新认领。遇到此提示请保留原目录，并按上述新的空目录方式安装／解压。卸载前若身份登记或自有目录被占用，卸载不会开始；释放占用后可重试。登记无效时卸载仅移除安装登记和可确认指向本次安装的开机启动项，保留程序文件，并提示使用新的空目录。

两种版本使用同一份当前用户配置，因此切换版本前应先从托盘退出旧实例，不要同时运行。正常配置位置：

```text
%LOCALAPPDATA%\BaomihuaDanmuCompanion\api.dat
%LOCALAPPDATA%\BaomihuaDanmuCompanion\app\preferences.json
%LOCALAPPDATA%\BaomihuaDanmuCompanion\app\webview-evergreen\
```

API 地址继续使用当前 Windows 用户的 DPAPI 加密，并兼容 preview.15 的固定保存位置。Portable 并不把 API 凭据导出到移动介质；换账户或换电脑后应重新输入，不要把加密文件当成通用明文备份。

共享浏览器使用新的 `webview-evergreen` 缓存目录，不会用较旧共享 Runtime 打开 beta.1 的 `webview` 私有浏览器资料；原 API 和显示偏好仍沿用。不要手动复制旧浏览器资料到新缓存目录。

旧预览版解压目录里的 `.cache/app/preferences.json` 不会被自动搜索或删除。首次从旧预览版切换时，API 已保存则继续读取，显示偏好可在新版本重新设置；需要迁移旧偏好时，应先关闭两版、备份原文件，再复制到上述新位置。不要复制旧浏览器资料或把实际配置文件上传 GitHub。

如果 preview.15 已启用开机启动，Beta 会识别精确匹配的旧脚本快捷方式。在 Beta 中先关闭“开机自动启动”，再按需重新开启，即改为当前目录的原生 EXE；读取状态不会执行旧 PowerShell。没有旧启动项的用户仍默认关闭。卸载器仅清理指向本次安装的原生启动项，不删除旧版或其他副本的启动项。

安装版升级应先退出程序，继续安装到原目录，当前用户配置不会作为程序文件覆盖。需要改到另一个目录时，建议先卸载原安装，再安装到新位置。Portable 升级请解压到新文件夹，不要混合覆盖不同版本的运行库。

从本地 beta.1 完整离线安装版升级时，请先卸载旧安装，再安装精简版。已登记的安装不能直接换到另一个目录，以免旧文件失去卸载登记。旧 Portable 可保留，精简 Portable 请另解压到新空目录。安装器会拒绝直接覆盖包含 `WebView2Runtime` 的旧布局，避免遗留大浏览器。

安装版可从 Windows“已安装的应用”卸载。卸载只移除该安装拥有的文件和快捷方式，默认保留上述当前用户配置。Portable 退出后可删除程序文件夹。若要彻底清除个人数据，先在面板清空并保存 API 地址、关闭开机启动、退出所有实例，再自行删除上述数据目录；这会同时影响安装版和 Portable 的共同配置。

## Beta 验证边界

本版面向 Windows 10/11 x64；当前验收环境为 Windows 11 x64，不把单机结果外推为 Windows 10 的完整兼容性证明。ARM64、网络共享运行和不同安全策略环境未作兼容性承诺。

应用显式请求稳定版 Runtime，并清理继承的浏览器／调试环境覆盖；受管电脑的 WebView2 注册表策略仍可能改变 SDK 的选择。此类策略环境未验证，不应通过关闭系统安全策略来强行运行。

从脚本改为 EXE 不代表之前尚未完成的多屏 DPI、长期真实播放、严格延迟及所有窗口焦点场景已经通过。本版仍是 Beta，不宣称 preview.15 尚未完成的性能目标已经达成。

已有 WebView2 时程序界面能离线启动，但搜索和下载真实弹幕仍需要你配置的服务可达。若提示缺少 WebView2，请运行微软引导程序；若提示应用文件缺失，请完整解压或重新安装同一版本，不要混入旧版脚本／依赖。
