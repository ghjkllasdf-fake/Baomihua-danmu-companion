# 爆米花弹幕伴侣 0.2.5（普通版）

普通版需要你自行准备兼容弹弹play API v2 的弹幕服务地址。没有服务地址时，可选择 [内置服务版（includeAPI）](https://github.com/ghjkllasdf-fake/Baomihua-danmu-companion/blob/main/docs/INCLUDEAPI-USER-GUIDE.md)。播放器和视频需要自行准备；获取弹幕需要联网。

## 安装和运行

- **安装版**：运行 `DanmuCompanion-0.2.5-win-x64-setup.exe`，选择当前用户可写的本地专用文件夹，完成后从开始菜单打开。
- **免安装版（Portable）**：完整解压 `DanmuCompanion-0.2.5-win-x64-portable.zip`，运行其中的 `DanmuCompanion.exe`。不要在压缩包中直接运行，也不要只复制一个 EXE。

两版都使用系统 WebView2 运行环境（最低 124）。缺少时，安装版会联网安装；免安装版请运行包内的 `MicrosoftEdgeWebview2Setup.exe`。不需要另装 .NET、Node 或 PowerShell。若选择的安装位置不可写，请换一个位置，不要关闭系统安全功能。

1. 打开伴侣，点击系统托盘图标展开面板。
2. 在面板顶部填写弹幕服务地址，点击“保存地址”。支持直接地址和路径中的访问令牌；不支持依赖网页登录、Cookie、查询参数令牌或额外请求头的服务。
3. 在爆米花中播放视频，等待搜索和加载弹幕。找错作品时，点击“手动搜索 / 换源”。

服务地址会由当前 Windows 用户加密保存。请只使用可信服务；搜索和获取弹幕时，作品信息会发送到你填写的地址。更换账户或电脑后可能需要重新填写。

## 调整弹幕

托盘面板可设置显示区域、字号、速度、透明度、描边、阴影、缩放和密度。全新配置默认显示上半屏、字号 22、速度 0.6 倍、不透明度和阴影 100%、描边 0，并开启等比缩放和密集弹幕；已有设置不变。顶部弹幕固定显示；底部弹幕需要选择“全屏”并启用底部类型。

兼容的播放器窗口在控制栏出现时会显示弹幕开关和快捷设置按钮；鼠标移到设置按钮即可展开。无法识别控制栏时，这两个按钮不会出现，但仍可使用托盘面板。首次打开面板时，界面尚未就绪会先显示加载提示。

“更多设置”中可调整弹幕类型、关键词过滤、重复弹幕合并和时间偏移。弹幕时间不合适时先核对来源和集数；时间偏移的正值让弹幕晚出现，负值让弹幕早出现。无法读取播放时间时，可使用手动时间校准。

部分播放器首次同步可能需要等待；无法直接获知倍速时，首次同步可能约需 10 秒，之后的倍速变化也可能不会立即生效。多季作品缺少可靠季数信息时，需要手动选片／选集。伴侣不会修改字幕内容或播放器设置。

## 更新与卸载

“更多设置 → 软件更新”可以按每天、每周或每月检查新版，也可手动检查；发现新版后需自行下载，程序不会自动安装或替换文件。

更新或切换版本前，请从托盘退出伴侣。安装版通常安装到原目录；要更换目录时先卸载旧版。免安装版请完整解压到新文件夹。安装版会覆盖安装清单内的同名程序文件，请不要在这些位置放置个人文件。

卸载安装版请使用 Windows“已安装的应用”；免安装版退出后删除程序文件夹。卸载默认保留个人设置，安装目录中的额外文件也可能保留。移动或删除程序文件夹前，先关闭伴侣的开机启动，之后可按需重新开启。

个人配置位于 `%LOCALAPPDATA%\BaomihuaDanmuCompanion`。普通版与内置服务版共享显示设置；彻底清除个人数据会同时影响两版。若确需清除，请先清空并保存服务地址、关闭开机启动、退出所有实例，再自行删除该目录。

## 常见问题与安全

- **找不到窗口**：伴侣默认驻留托盘，请展开任务栏的隐藏图标。
- **没有弹幕或选错作品**：确认弹幕开关、网络和服务地址，等待搜索；必要时手动搜索并核对作品和分集。
- **提示播放器以管理员身份运行**：保存操作并退出播放器，以普通方式重新打开，然后从托盘退出并重启伴侣。不要将播放器或伴侣设置为永久管理员运行；伴侣不会自动提权。
- **字幕交互无响应**：可先退出外部自动化或调试工具，再重启播放器。既有字幕验收在未运行这类工具时完成，不代表已确认唯一原因或所有工具都存在问题。
- **文件缺失或面板白屏**：完整重新安装／解压；缺少 WebView2 时运行包内的微软安装引导程序。

应用和安装包尚未签名，Windows 可能提示未知发布者。请从项目发布页下载，必要时使用同版本 `SHA256SUMS.txt` 核对文件；校验值不能替代发布者签名。不要为运行程序关闭杀毒软件。

详细许可见 `THIRD-PARTY-NOTICES.md` 和 `licenses/`；Microsoft WebView2 使用独立条款。Windows 10、所有播放器布局、多屏和长期播放环境并未全部验证。
