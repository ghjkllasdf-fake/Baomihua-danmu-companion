# preview.11 安全与隐私审查说明

审查日期：2026-10-28。对象为本次公开源码和 Windows x64 预览包，不包含用户自己的后端服务、播放器和操作系统。

## 信任边界

- 播放器窗口、UIA/媒体会话以及弹幕 API 返回的数据都按外部输入处理。
- 搜索片名和分集请求发送到用户配置的 API。支持局域网服务是产品用途，因此没有把所有私网地址一律禁止；互联网访问建议 HTTPS。
- React 只通过有类型和运行时校验的命令桥调用本地宿主，不提供任意脚本、文件路径或进程执行接口。
- 便携运行时、SDK 和打包文件按固定校验值及清单核对。

## 本次处理

- 公开内容排除本机私有 API 默认值、Token、用户目录、开发交接记录、观看记录、运行缓存、截图及历史测量产物。
- 发布入口不再读取旧脚本里的私有默认地址；普通用户在界面配置，或显式使用 `DANMU_API_BASE` 环境变量。地址不写入显示偏好。
- 补齐 WebView2 SDK 下载校验、固定工具版本约束和 PowerShell 下载的固定 SHA256 校验。
- 发行必需文件清单包含当前全部原生模块，避免新增模块未被列为必需文件。
- 保留 HTTP/HTTPS 地址校验、禁止重定向、响应大小/数量限制、整体请求超时与取消、API 错误地址脱敏。
- 保留本地界面来源校验、导航/新窗口/权限限制、浏览器自动填充和密码保存禁用；普通入口不开放调试端口。
- Git 发布使用明确文件集合和不含个人邮箱的提交身份。第三方许可中的原作者及版权信息保留原文。
- npm 对固定锁文件的审计未报告已知漏洞；发布前还核对源码索引、ZIP 清单、已知私有信息排除和包内启动/退出。

## 本次验证结果

- 固定锁文件的 npm 审计：0 个已知漏洞，未执行强制升级。
- 前端：lint、类型/生产构建、140项单元测试、41项浏览器回归通过。
- 原生：全套回归通过，另行核对命令桥来源边界、启动器、缺依赖处理及 SDK 冷解压。
- 隐私工具：7项回归通过；Git 索引扫描未发现真实凭据、个人目录、非占位邮箱或私网服务地址。虚拟来源拒绝测试中的固定假凭据按受控样例处理。
- Release：发布前核对已知私有信息排除、全部包内文件清单、包内独立启动/握手和正常退出。

## 审查边界

这是一轮源码审查、依赖审计、隐私扫描与运行回归，不是独立渗透测试或安全认证。没有发现某类问题，不代表不存在未知漏洞。

清单和 SHA256 用于发现缺失或损坏，不是数字签名。请从本仓库 Release 获取文件。多屏、长时间观看以及所有播放器版本尚未全部验证，当前仍为预览版。
