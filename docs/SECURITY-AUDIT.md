# preview.15 安全与隐私审查说明

首次审查日期：2026-10-28；本版复核日期：2026-10-29。对象为公开源码和 Windows x64 预览包，不包含用户自己的后端服务、播放器和操作系统。

## 信任边界

- 播放器窗口、UIA/媒体会话以及弹幕 API 返回的数据都按外部输入处理。
- 搜索片名和分集请求发送到用户配置的 API。支持局域网服务是产品用途，因此没有把所有私网地址一律禁止；互联网访问建议 HTTPS。
- React 只通过有类型和运行时校验的命令桥调用本地宿主，不提供任意脚本、文件路径或进程执行接口。
- 便携运行时、SDK 和打包文件按固定校验值及清单核对。

## 本次处理

- 公开内容排除本机私有 API 默认值、Token、用户目录、开发交接记录、观看记录、运行缓存、私人截图及历史测量产物。README 只使用已审查的自制／示例预览图。
- 发布入口不再读取旧脚本里的私有默认地址；普通用户在界面配置，或显式使用 `DANMU_API_BASE` 环境变量。地址不写入显示偏好。
- 补齐 WebView2 SDK 下载校验、固定工具版本约束和 PowerShell 下载的固定 SHA256 校验。
- 发行必需文件清单包含当前全部原生模块，避免新增模块未被列为必需文件。
- 保留 HTTP/HTTPS 地址校验、禁止重定向、响应大小/数量限制、整体请求超时与取消、API 错误地址脱敏。
- 保留本地界面来源校验、导航/新窗口/权限限制、浏览器自动填充和密码保存禁用；普通入口不开放调试端口。
- Git 发布使用明确文件集合和不含个人邮箱的提交身份。第三方许可中的原作者及版权信息保留原文。
- npm 对固定锁文件的审计未报告已知漏洞；发布前还核对源码索引、ZIP 清单、已知私有信息排除和包内启动/退出。
- 开机启动默认关闭，只有显式布尔命令才能创建或移除本程序在当前用户启动文件夹中的固定名称快捷方式。界面不能指定任意目标路径或命令；快捷方式不包含 API 地址或 Token，不要求管理员权限。
- 托盘文字对外部名称清理控制字符、截短并限制长度；换集和修改 API 时清除旧来源。关闭工作台保留当前会话，显式退出或释放窗口时清理图标、后台探测和覆盖层。
- 后台打开的画面检查包含浏览器控制器显示状态、真实 DOM 可见性、布局尺寸和非空白帧；首次打开、重开及最小化恢复均纳入回归。
- 发行必需清单包含应用与托盘 ICO 及加载模块；图标只读取本地固定路径，开机启动快捷方式显式引用本应用图标。
- 按用户新要求增加 API 持久化：仅显式 `save-api` 命令写入固定路径，参数严格限制为地址；界面不能提供文件路径。先用 Windows DPAPI CurrentUser 加密，再原子替换；失败不替换活动服务和旧保存值。读取有16KiB上限，损坏／解密失败给通用提示并保留原文件。
- API 文件独立于显示偏好，使用当前用户 LocalAppData，升级仍可读取；测试 profile 使用隔离目录。清空并保存可删除记录。不使用浏览器存储、不将地址加入启动命令或日志。相同 Windows 用户的程序可使用同一用户数据保护能力，本机制不能抵御已控制该账户的程序。

## 本次验证结果

preview.15 验证 API 加密往返、非明文文件、大小／篡改拒绝、失败写入保留、显式移除、新工作台恢复、命令参数边界、保存按钮状态与页面重开恢复，并复核发行包和隐私排除。README 演示图不是播放器识别或实时画面性能验收。

- 固定锁文件的 npm 审计：0 个已知漏洞，未执行强制升级。
- 前端：lint、类型/生产构建、145项单元测试、45项浏览器回归通过。
- 原生：新增 API 保存／恢复、实际桌面命令处理、发行校验及托盘画面检查通过；显示偏好、自动匹配和来源边界另行复核。测试没有启用实际用户的开机启动或保存真实 API。
- 实窗焦点回归在此前桌面会话无法取得目标窗口前台焦点，对未修改的 preview.11 复核也出现相同失败。本轮未改该逻辑、未重跑完整 Native all，不将这个检查记为本版通过。此前版本的通过记录不替代本版结果。
- 隐私工具：8项回归通过；Git 索引扫描未发现真实凭据、个人目录、非占位邮箱或私网服务地址，并拒绝意外纳入的 `api.dat`。虚拟来源拒绝测试中的固定假凭据按受控样例处理。
- Release：发布前核对已知私有信息排除、全部包内文件清单、包内独立启动/握手和正常退出。

## 审查边界

这是一轮源码审查、依赖审计、隐私扫描与运行回归，不是独立渗透测试或安全认证。没有发现某类问题，不代表不存在未知漏洞。

清单和 SHA256 用于发现缺失或损坏，不是数字签名。请从本仓库 Release 获取文件。多屏、长时间观看以及所有播放器版本尚未全部验证，当前仍为预览版。
